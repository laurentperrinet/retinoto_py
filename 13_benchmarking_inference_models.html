Comprehensive Inference Benchmarking¶

This notebook provides a unified benchmark of various convolutional neural network (CNN) architectures, including standard baselines and retrained weights. We evaluate the trade-off between:

  • Accuracy: Performance on validation datasets.

  • Computational Cost: Inference speed (wall clock time) and model complexity (total parameters).

  • Masking Impact: The effect of partial image masking (do_mask) on performance across different architectures.

We compare three main categories of models:

  1. Baseline ResNets: Standard pre-trained architectures (ResNet18, 50, 101).

  2. ConvNeXt family: Scaling analysis across Tiny, Small, Base, and Large variants.

  3. Retrained Models: Models that have been specifically retrained on masked/bbox data (from script 21).

Benchmarking Loop¶

We iterate over all ResNet architectures and all datasets and masking configurations. For each combination, we load the standard pre-trained model weights.

[3]:

# 3. Main Benchmarking Loop: Iterating over datasets, masking options, and models
json_filename = args.data_cache / '13_model_comparison.json'

# %rm {json_filename}  # FORCING RECOMPUTE

if json_filename.exists():
    results = fovea.pd.read_json(json_filename)
else:
    all_results = []
    # Test both with and without masking to see the impact on performance
    for do_mask in [True, False]:
        for dataset in fovea.params.all_datasets:
            args = fovea.Params(do_mask=do_mask, do_fovea=False, do_augment=False)
            # Load the validation data loader for the given dataset
            val_loader = fovea.get_val_loader(args, dataset)
            for model_name in fovea.params.all_rn_model_names:
                args.model_name = model_name
                model = fovea.load_model(args)
                param_stats = fovea.count_parameters(model)
                total_layers = fovea.count_layers(model)
                tic = fovea.time.time()
                # Measure accuracy and timing
                accuracy = fovea.get_validation_accuracy(args, model, val_loader, f"Model {model_name}\t dataset: {dataset}\t(do_mask={do_mask})")
                toc = fovea.time.time()
                this_result = { 'model_name': model_name,
                                'do_mask': do_mask,
                                'dataset': dataset,
                                'accuracy': accuracy,
                                'wall_clock_time': (toc-tic)/len(val_loader.dataset),
                                'total_parameters': param_stats['total_parameters'],
                                'trainable_parameters': param_stats['trainable_parameters'],
                                'total_layers': total_layers}
                all_results.append(this_result)
    results = fovea.pd.DataFrame(all_results)
    results.to_json(json_filename, orient='records', indent=2)
